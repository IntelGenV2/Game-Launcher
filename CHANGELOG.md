# Changelog

## 0.3.12

- The startup cartridge now has twelve color stripes, keyed gold contacts, and clips that close as it docks. The circuit traces keep pulsing in your selected theme through the Studio 256 title.
- The Studio 256 name fades from white to your theme color in the desktop title bar and Big Picture.
- The Windows installer refreshes the striped cartridge icon in Installed Apps, Start menu and desktop shortcuts, and existing taskbar pins, including renamed pins.

## 0.3.11

- An animated 3D Studio 256 title appears as the cartridge docks. Color pulses keep moving along the circuit traces while the title is visible and as the library fades in.
- Turn the intro on or off in **Settings → Appearance → Play startup animation**. Reduced motion still opens the library directly.
- The Windows installer refreshes the cartridge icon on desktop and Start menu shortcuts and existing taskbar pins, including renamed pins.

## 0.3.10

- The launcher opens with the Studio 256 C64 cartridge sliding into its socket as the circuit traces grow in your theme color. The three boxes on the cartridge label stay in place through docking.
- Click or press Escape, Space, or Enter to skip the opening. The launcher opens directly to the library when reduced motion is enabled in Windows or the app.
- The Windows app, installer, shortcuts, and taskbar use a rounded, letter-free Studio 256 cartridge icon.

## 0.3.9

- The title bar gives the full Studio 256 name room beside Search.
- Fixed a crash when opening hardware details and corrected the labels for Windows storage devices.
- Settings, System, and navigation buttons use dark recessed surfaces. Removed decorative glow effects from the library and Big Picture.
- Windows shortcuts and existing taskbar pins use the Studio 256 cartridge icon.

## 0.3.8

- Renamed the app to **Studio 256 Game Launcher** and added the Studio 256 cartridge icon to the desktop, Big Picture, and Windows installer.

- **Big Picture** is controller-first: **B** focuses the left rail (it pops out); up/down highlight, **A** selects. Library: left/right on the wheel, up opens a folder or game info, down closes a folder. Browse uses a smaller filter list plus an on-screen keyboard.
- Opening Big Picture covers the library first, then the window goes fullscreen.
- Groups in Big Picture use the same fanned cover stack as the desktop library. Opening a group slides covers out of the fan; closing slides them back in, then the rest of the library slides back onto the wheel.
- Grouped covers keep that group’s accent border on the desktop grid and in Big Picture, including stacked covers while the group is closed.
- System power actions (sleep, lock, restart, shut down) ask for confirmation; Cancel is the default.
- Files in Big Picture: left/right move place chips or the file list, up/down moves between those rows, A / Enter selects. Controller B / LB / RB still work; extra keyboard shortcuts are off on that screen.
- Only one launcher instance is allowed; a second start focuses the existing window (including when it is in the tray).
- Optional **IGDB** covers and metadata via Twitch Client ID + Secret (Settings → Covers). Identifies the actual game by Steam ID or name — not Discord’s `.exe` matching.
